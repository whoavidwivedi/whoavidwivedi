# Avi Dwivedi

I design and build software, from the systems underneath to the details people notice.

## About me

I like building useful things, teaching what I know and learning what I don't.

Most of my work sits where live systems meet the screen: voice rooms that connect people in real time, the APIs behind them, and the interfaces people actually touch. I care a lot about that last part. Motion, feedback and small details should feel like part of how something works, never like decoration.

Teaching shaped how I build. Explaining code to someone else is the fastest way I know to find out what I don't understand yet, and it made me write simpler, clearer software.
